# interesting-vibe-coding 🐾

**Open-source terminal companions for AI coding agents.**

Your AI agent is thinking. You're waiting. Why not play a game?

## Projects

| Repo | What it does |
|------|-------------|
| [**paws**](https://github.com/interesting-vibe-coding/paws) | Terminal game launcher + HUD that shows your agent's status. Supports Kiro CLI, Claude Code, and Codex CLI. |
| [**paws-games**](https://github.com/interesting-vibe-coding/paws-games) | A collection of terminal games — Dog Jump, Pinball, Earth Online, Poetry Scroll. |

## Quick Start

```bash
cargo install --git https://github.com/interesting-vibe-coding/paws        # the launcher
cargo install --git https://github.com/interesting-vibe-coding/paws-games   # game pack
```

Then press **CMD+G** in [Kaku](https://github.com/nicholasgasior/kaku) to start playing.

## Philosophy

- **Zero config** — install and go, the HUD auto-detects running agents
- **Plugin-friendly** — any TUI binary on your PATH can be a game
- **Lightweight** — install only the games you want
